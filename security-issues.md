# Qoption security audit

Static review of the Qoption working tree on 2026-11-26. The review covered Cloud Functions, Firebase rules, identity and staff permissions, financial workflows, browser rendering and exports, and deployment configuration. The linked repository supplied review guidance and was accessed as public documentation. [OWASP Top 10:2025](https://top10.owasp.org/2025/) · [Link Shortener security audit prompt](https://github.com/AlexL70/linkshortener/blob/main/.github/prompts/security-audit.prompt.md) · [Repository security instructions](https://github.com/AlexL70/linkshortener/blob/main/AGENTS.md#8-security-rules-must-be-implemented-before-any-public-release)

Qoption's security plan describes a demo. Severity for funds-related findings reflects potential impact if balances can be redeemed or approved requests lead to payouts. Staff account provisioning and production payment configuration remain unverified. The review covered dependency lockfiles. Automatic approval review blocked the npm registry advisory check because it would transmit dependency metadata to npm. [Qoption security plan](docs/SECURITY.md)

## Additional findings

- **Medium.** The fallback deposit QR sends the beneficiary's payment details to an external image service and trusts its response. Uploaded QR images and the displayed beneficiary fields can also diverge. Generate the QR locally from one validated beneficiary record and audit changes to it. [QR rendering](apps/web/shared/client-ui.ts#L570) · [Deposit settings](functions/src/index.ts#L382)
- **Medium.** Authenticated home and history reads can trigger settlement work and market-data requests outside the mutation quota. Apply per-principal request budgets and move quote resolution and settlement to bounded, deduplicated jobs. [Settlement sweep](functions/src/index.ts#L320) · [History endpoint](functions/src/index.ts#L1069)
- **Low.** CSV exports quote transaction text and leave formula interpretation to the spreadsheet application. Treat user-controlled cells as typed text or neutralize formula-leading values before export. [CSV encoding](apps/web/shared/client-ui.ts#L1215) · [Transaction export](apps/web/shared/app.ts#L1862)
- **Low.** The checked-in Hosting workflow uses a service-account key and deploys on pushes to main. Use a least-privilege federated deployment identity and require dependency and integration checks for release. Repository branch protection and cloud IAM settings remain unverified. [Hosting workflow](.github/workflows/firebase-hosting.yml#L23)
